# ABX-AI Frontend (React + Tailwind)

## Run locally

```bash
cd frontend
npm install
npm run dev
```

The app runs by default at `http://localhost:5173` and calls backend APIs at `http://localhost:8000`.

## Features
- Mobile responsive form-based workflow.
- Recommendation panel with antibiotic plan + resistance probabilities.
- AMS alert chips for stewardship checks.
